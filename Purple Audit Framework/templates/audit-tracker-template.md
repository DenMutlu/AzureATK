# Audit Tracker Template

Use an audit tracker to keep controls, evidence, findings, and recommendations structured.

## Recommended columns

- ID
- Domain
- Control Name
- Description
- Validation Type
- Tool / Source
- Evidence
- Result
- Risk
- Findings
- Recommendation
- Owner
- Audit Name
- Comments

## Suggested usage

### ID
A unique identifier for each control or review item.

### Domain
The audit domain, such as:

- Identity Surface
- Privileged Access
- App and Workload Permissions
- Cross-Tenant Trust
- Logging and Detection

### Validation Type
Examples:

- configuration review
- safe simulation
- log validation
- manual review
- evidence collection

### Result
Examples:

- compliant
- partially compliant
- non-compliant
- not applicable
- needs clarification

## Practical notes

- keep wording consistent across findings
- tie evidence to a clear review step
- avoid storing more sensitive data than needed
- use the tracker to support both reporting and follow-up work
